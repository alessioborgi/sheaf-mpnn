The repository also contains a
[`CITATION.cff`](https://github.com/alessioborgi/sheaf-mpnn/blob/main/CITATION.cff)
file, which GitHub uses for its "Cite this repository" button.

Please also cite the papers that introduced the models you use; they are
listed in the [Models](user-guide/models.md) table.
