# Bayesian Sheaf Neural Networks (BSNN)

This package implements **Bayesian Sheaf Neural Networks** (Gillespie, Bou
Hamdan, Schizas, Boothe & Maroulas, 2025 — [arXiv:2410.09590](https://arxiv.org/abs/2410.09590))
on top of this library's message-passing NSD formulation. The cellular sheaf
is treated as a **latent random variable**: a variational sheaf learner maps
node features to a distribution over restriction maps, each diffusion layer
runs with its own i.i.d. sheaf sample, and training maximizes the evidence
lower bound (ELBO).

## Core Concept

The deterministic NSD sheaf learner is replaced by a variational posterior
$q_\phi(\mathcal{F} \mid X, y)$ that factors over incident node-edge pairs
$u \trianglelefteq e$. For each pair, bias-free linear heads map the
concatenated features $[x_u \,\|\, x_{u'}]$ to distributional parameters
$(\mu_{u \trianglelefteq e}, \sigma_{u \trianglelefteq e})$ (paper Eq. 21) —
**once per forward pass**. One sheaf $\mathcal{F}_\ell$ is then sampled per
layer (Algorithm 1), and each layer applies the standard NSD update

$$\mathbf{X}^{(t+1)} = (1 + \tanh\varepsilon)\,\mathbf{X}^{(t)} - \alpha\,\sigma\!\left(\Delta_{\mathcal{F}^{(t)}} \left(\mathbf{I}_n \otimes \mathbf{W}_1\right) \mathbf{X}^{(t)} \mathbf{W}_2\right)$$

with the *sampled* sheaf Laplacian $\Delta_{\mathcal{F}^{(t)}}$.

### Restriction-map families

| Variant | Posterior | Prior | KL |
|---|---|---|---|
| `diagonal` | $\mathcal{N}(\tanh\mu, \operatorname{diag}(\sigma^2))$ per diagonal entry | $\mathcal{N}(0, I)$ | closed form |
| `general` | $\mathcal{N}$ over all $d^2$ entries | $\mathcal{N}(0, I)$ | closed form |
| `orthogonal` | Cayley distribution $\mathcal{C}_d(M, \kappa)$ on $SO(d)$ | uniform on $SO(d)$ | closed form for $d \in \{2, 3\}$ (paper Prop. 3), Monte Carlo for $d \ge 4$ |

### Cayley distributions on SO(d)

The $SO(d)$ posterior uses the paper's reparameterizable **Cayley
distribution** (Definition 8): with $X$ Haar-uniform on $SO(d)$ and $C$ the
(involutive) Cayley transform,

$$Y = C\!\left(\tfrac{1-\kappa}{1+\kappa}\, C^{-1}(X)\right) M \;\sim\; \mathcal{C}_d(M, \kappa).$$

The mean rotation $M$ comes from the configured `orth_strategy`
(Cayley/Householder parameterizations shared with the deterministic NSD
layers); the concentration head outputs one scalar per map. The density
(Theorem 1) $f_d(P; M, \kappa) = (1-\kappa^2)^{d(d-1)/2} \det(P M^\top - \kappa I)^{1-n}$
backs the Monte Carlo KL estimate for $d \ge 4$.

### Symmetry of the sampled Laplacian

Sampled maps are indexed per incident node-edge pair. For each directed edge
$(u, v)$ the layer needs $(F_{v \trianglelefteq e}, F_{u \trianglelefteq e})$;
`reverse_edge_permutation` gathers the destination map from the reverse
directed edge so every incident pair is **sampled exactly once** and the
resulting sheaf Laplacian stays symmetric positive semi-definite.

## Training: the ELBO

`BayesSheafLightningModule` optimizes the negative ELBO (paper Eq. 19/20)

$$\mathcal{L} = \mathrm{CE}(\hat{y}, y) + \lambda_t \, \mathrm{KL}\!\left(q_\phi(\mathcal{F} \mid X, y) \,\|\, p(\mathcal{F})\right),$$

where $\lambda_t$ follows the cyclical sigmoid annealing of Fu et al. (2019)
used by the reference implementation
($\lambda_t = \lambda_{\max} \cdot \operatorname{sigmoid}(20\,\mathrm{frac}_t - 10)$
per `kl_cycle`-epoch window). Config knobs: `use_kl`, `kl_weight`,
`kl_anneal` (`cyclical`/`constant`), `kl_cycle`.

## Evaluation: ensembling and uncertainty

At evaluation time the module averages softmax probabilities over
`ensemble_size` stochastic forward passes and reports the paper's
uncertainty-quantification metrics (Section 2.5) alongside accuracy:
predictive entropy, epistemic variance, mutual information, and expected
calibration error (`val_pred_entropy`, `val_epistemic_var`,
`val_mutual_info`, `val_ece`, and the `test_*` counterparts).

## Usage

```python
from sheaf_mpnn.bsnn import BSNNModel, BSNNVariant

model = BSNNModel(
    in_channels=1433,
    out_channels=7,
    stalk_dim=3,
    hidden_dim=32,
    num_layers=2,
    variant=BSNNVariant.ORTHOGONAL,
)
logits = model(x, edge_index)   # one stochastic pass; KL available via
kl = model.kl_loss()            # the same forward
probs = model.predict_proba(x, edge_index, num_samples=5)  # [T, N, C]
```

Benchmark runs and sweeps go through the standard CLI:

```bash
# 10-fold cross-validation with the tuned preset
sheaf run --preset cora_bsnn_orthogonal

# Optuna sweep (one YAML per dataset/variant under configs/<dataset>/bsnn/)
sheaf sweep --yaml-path configs/cora/bsnn/orthogonal.yaml --preset cora_bsnn_orthogonal
```

Presets follow the family grid: `<dataset>_bsnn_<variant>` for every node
dataset and `variant` in `{diagonal, general, orthogonal}`. The sweep YAMLs
are generated by `scripts/gen_bsnn_sweeps.py`.

## Files

- `variational.py` — Cayley distributions on $SO(n)$ (sampling, densities,
  KL divergences) and the three variational sheaf learners.
- `bsnn_layers.py` — `Diagonal/General/OrthogonalBSNNConv`: NSD diffusion
  layers consuming externally sampled maps (built on `BaseSheafConv` /
  `BaseNSDConv`).
- `bsnn_model.py` — `BSNNModel` (encoder → sampled sheaf layers → decoder),
  `BSNNVariant`, `reverse_edge_permutation`.
- `uncertainty.py` — entropy / epistemic variance / mutual information / ECE.
